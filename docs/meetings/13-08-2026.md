## **2\. Puntos Tratados y Acuerdos Técnicos**

### **2.1. Arquitectura de Contenedores y Desacoplamiento (Docker Isolation)**

* **Definición de Contenedores**:  
  1. intellops-core: Engine en FastAPI para recepción asíncrona de tráfico RUM, autenticación de usuarios/aplicaciones y persistencia inicial.  
  2. intellops-ai-engine: Pipeline analítico (Isolation Forest \+ LLM Llama 1B local). Se mantendrá aislado para evitar que un fallo de memoria (OOM) o sobrecarga en la inferencia afecte la ingesta del Core.  
  3. intellops-db: Instancia de PostgreSQL (soporte nativo JSONB y trazabilidad del DER V1.2).  
  4. intellops-comms: Microservicio despachador de alertas para integración con APIs externas (Telegram, WhatsApp, Email).  
* **Estrategia para el Frontend**: Se acuerda postergar la construcción del Dashboard completo (UI rica en gráficos) para las etapas finales del proyecto (Sprint 3/4). Para el corto plazo, se utilizará una interfaz/mock mínima para pruebas E2E e informes de avance, priorizando la estabilidad del Backend y del motor de IA.
